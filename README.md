# Chat Application (Tkinter + Sockets)

## Objective
To develop a GUI-based chat application using Python socket programming and Tkinter that supports real-time communication.

## Steps Performed
- Implemented client–server architecture using Python sockets
- Designed a Tkinter-based GUI chat window
- Enabled real-time message exchange between multiple clients
- Stored chat messages in a file for message history
- Added basic emoji support in messages

## Tools Used
- Python
- Socket Programming
- Tkinter
- VS Code
- GitHub

## Outcome
A functional chat application that allows multiple users to communicate in real-time through a GUI, with message history and emoji support.
